1. I am assigned a project to design an adaptive learning tutor inspired from OATutor. In this software, students are able to select a topic and they are given MCQ questions. Each question is tagged / associated with a 3-tuple, the topic of the question, the bloom's taxonomy level of the question and the associated skills. Depending on their answer we update our system's internal understanding of their mastery level of different different skills using Bayesian Knowledge Tracing.

I am assigned with designing the data structure that will hold the skill tree and the traversal / update algorithm that will update the system's internal understanding of a student's skill mastery levels with regard to bloom's taxonomy.

My current requirements for the skill tree is that the skill tree contains some root nodes called pre-requisite skills that are the most atomic / basic skills available that dont require any skills to learn. These are followed by derived skills that have one or more skills as parents that need to be learnt before these skills are accessible. Each skill is associated with multiple topics and the list of topics they are they are associated with must be stored in the skill tree.

When a student gets a question right, we intend to update the system's internal understanding of his mastery level of different skills using bloom's taxonomy. My current idea is to represent the mastery level of each skill between 0 to 100%, where each interval between 0-100 represents a bloom's skill level, such as 80-100% representing create level, etc. When a student answers a question correctly, we increase the mastery levels of the skills he is tagged with by an amount proportionally related to his current mastery level and the bloom's level associated with the question, and increase the mastery level of the pre-requisite / parent skills of the updated skills either by the same amount or a decayed amount (I leave that up for you to decide). When a student gets a question wrong, we decrease their mastery level in the same amount.

I need to develop this structure, the algorithm required ot update the student's mastery level and implement bayesian knowledge tracing in python, while maintaining OOP standards so any of these can be easily replaced later on. Can you implement these files for me.
